# MSME Financial Modeling

Practical financial modeling techniques tailored for Indian MSMEs.

## Techniques covered
- NPV & IRR
- Sensitivity analysis
- Scenario modeling (Optimistic / Base / Pessimistic)
- Cash conversion cycle
- Simple Monte Carlo simulation (optional)

## Quick start
```bash
pip install numpy-financial numpy
python npv_irr.py
python scenarios.py
```

All examples use realistic MSME-scale numbers (₹).
